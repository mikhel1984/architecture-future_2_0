# Проблемы

- отчеты строятся часами - задержки в принятии управленческих решений
- использование устаревшего ПО (СУБД) - ограничивает возможности масштабирования системы
- система развернута на локальном сервере - необходимы расходы на оборудование и команду, обеспечивающие бесперебойную работу под нагрузкой и соответствие требованиям информационной безопасности
- все данные хранятся в DWH - увеличение ожидания пользователей системы с ростом количества неструктурированных данных

# Приоритеты (MoSCoW)

- длительное построение отчетов - must have
- устаревшее ПО - should have
- локальный сервер - could have
- все данные в DWH - should have
