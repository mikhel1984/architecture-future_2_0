# Домены

- Медицинские услуги
  - поддомен регистратуры
    - контекст: заключение договоров
    - контекст: запись к специалистам
  - поддомен специалистов
    - контекст: лечение пациентов
  - поддомен данных
    - контекст: управление хранением и обработкой структурированных медицинских данных

- Административно-хозяйственное управление
  - поддомен бухгалтерии
    - контекст: бухгалтерский учет и аудит
  - поддомен персонала
    - контекст: учет сотрудников
  - поддомен оборудования
    - контекст: учет оборудования
  - поддомен данных
    - контекст: управление хранением и обработкой административно-хозяйственнымх данных

- Фин-тех услуги
  - поддомен платежей
  - поддомен данных
    - контекст: управление хранением и обработкой финансовых данных

- ИИ анализ
  - поддомен анализа
    - контекст: анализ данных с использованием ИИ
  - поддомен данных:
    - контекст: управление хранением и обработкой неструктурированных медицинских данных

- API для интеграции партнеров
  - контекст: предоставление данных партнерам
  - контекст: поддержка платежей

# Аргументация

Домены определены согласно закону Конвея, исходя из области решаемых задач, поэтому зоны ответственности практически не перекрываются и каждый домен может развиваться
независимо от прочих. 
Для управления данными предлагается использовать децентрализацию в концепции Data Mash, в каждый домен ответственнен за свою часть данных и занимается из обработкой 
и формированием продукта для других доменов-потребителей. Это должно уменьшить время на аналитику, повысить качество отчетов, а также улучшить безопасность за счет 
ограничения доступа к данным.
